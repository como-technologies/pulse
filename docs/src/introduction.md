# Introduction

Pulse is a verified-anonymous employee sentiment polling platform built by Como Technologies. It lets organizations continuously measure workforce sentiment with cryptographic privacy guarantees -- responses are provably anonymous, yet provably from authorized employees.

## Who This Is For

This documentation is the technical reference for the Pulse platform. It covers the product concepts, system design, and codebase structure.
