# API Reference

Rust API documentation generated by `cargo doc`.

## Crates

- [pulse-crypto](./api/pulse_crypto/index.html) — Blind signatures (RFC 9474) and AES-256-GCM AEAD
- [pulse-protocol](./api/pulse_protocol/index.html) — Wire types, newtypes, and serde definitions
- [pulse-identity](./api/pulse_identity/index.html) — Identity zone: token issuance, sampling engine, authentication, and session management
- [pulse-signal](./api/pulse_signal/index.html) — Signal zone: response collection and storage
- [pulse-client](./api/pulse_client/index.html) — Client-side protocol engine, typestate flow, and transport abstraction
- [pulse-server](./api/pulse_server/index.html) — Axum HTTP layer (routes, error handling, middleware)
- [pulse-relay](./api/pulse_relay/index.html) — Anonymizing relay: batching, shuffling, and forwarding
- [pulse-test-harness](./api/pulse_test_harness/index.html) — Test servers, mock transport, and simulation framework
